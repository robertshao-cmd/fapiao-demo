> 給人照著點的逐步表。每步都寫「預期看到什麼」——看不到就是 bug,記步號回報。
> 改完商家端四檔任一個,重跑 `python checks/verify-demo.py`(exit 0 才算完成)。

| **小程序貨架**(3 顆單元) | https://robertshao-cmd.github.io/fapiao-demo/mini/ |

Pages 的 HTML cache 是 600 秒。剛 push 完要測 → 網址後面加 `?v=<隨便數字>`,或手機長按重新整理。

**本機**

```bash
python -m http.server 8125 --directory .
```

→ `http://localhost:8125/merchant.html`;手機同網段用 `http://192.168.221.35:8125/merchant.html`
(IP 每次換 Wi-Fi/開機都可能變,用 `ipconfig` 重抓——這組是 0730 量的)。

**唯一硬限制**:雙端聯動走 BroadcastChannel,**同源才通**。`file://` 直開會正常渲染但聯動全部靜默失效。
兩種可行擺法:

- **A 單視窗**(適合一支手機給老闆看):只開 `merchant.html`,靠內建 3 分頁切換。iframe 同源,聯動一樣通。
- **B 雙視窗**(適合桌機演「即時彈進來」):同一個 origin 開兩個 tab —— tab1 `merchant.html`、tab2 `user.html?store=nuan`。

### 按鈕形制(對照微信卡券)

固定金額券(`amt>0`,結帳自動折抵)**預設不出現按鈕**,只有一行綠字說明 + 一條給現金付款邊緣情境用的底線小連結。
只有算不出固定折抵、只能人工核銷的比例券,才保留藥丸形主按鈕(radius 99px、品牌色填滿、高 32px、按壓縮放)——
對應微信卡券右側「去使用」主行動鈕。量到的實測值:`圓角 99px / 高 32px / 底色 rgb(47,169,140)`。

## 2.5 小程序貨架(mini:解毒吧／懂你地圖／財神開示)

下面每個「預期」都是在**建置後的靜態版**上實測到的字面值(0729 首測,0730 校準過)。

對不上先分兩種:**數字**對不上(毒值、76→69、1080×1350)= build 或 code 壞了,要修;
**文案**對不上 = 通常只是那句話改過了,把這份文件跟著更新就好。

版本怎麼確認:看 `mini/MANIFEST.json` 的 `stamp`,或任一單元的 `unit-kit.js?v=`。

你只要確認「線上的 stamp」跟「你手上這份 repo build 出來的 stamp」一致;

## 4. 給店家的 3 分鐘小實驗(一鏡到底,一支手機)

python verify-shop.py <shop-UUID>          # 驗店 + 檢查 enableInvoice
